# Toronto City Guide

A 5-page responsive travel guide website for Toronto — home, attractions, food & dining, transport, and contact — built with vanilla HTML, CSS and JavaScript.

## Features

- Responsive layout using CSS Grid, Flexbox, and media queries (breakpoints at 900px and 600px)
- Interactive category filtering on the Attractions and Food pages (vanilla JavaScript, no frameworks)
- Card-based UI with hover animations
- Contact page with a two-column layout, a validated HTML form, and an embedded Google Map
- Accessible markup: semantic HTML5 tags, alt text on all images, keyboard-navigable filters, labelled form fields

## Pages

| Page | Description |
|---|---|
| `index.html` | Home page with hero banner and featured attractions |
| `attractions.html` | Grid of 9 attractions with category filtering |
| `food.html` | Restaurant recommendations with category filtering and a local tips section |
| `transport.html` | TTC fares, PRESTO card info, and transport options across the city |
| `contact.html` | Contact form, visitor info, and embedded map |

## Tech used

HTML5, CSS3 (Grid, Flexbox), JavaScript
